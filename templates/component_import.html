Prepare your CSV

Required columns: sku, name, category, supplier, quantity, reorder_level, unit_price.

  • Use UTF-8 encoding, comma separators, and a header row. Maximum file size: 1 MiB; maximum records: 5,000.
  • Headers are case-insensitive; spaces can replace underscores. description is optional (omitting it clears existing descriptions). The export's Availability column is ignored and status is recalculated.
  • Category and supplier must match existing categories and suppliers. Matching ignores letter case.
  • Quantity and reorder level must be non-negative whole numbers up to 9223372036854775807. Unit price must be a finite, non-negative number.
  • An existing SKU updates that component; a new SKU creates one. Matching ignores letter case and surrounding spaces. Later duplicate rows and SKUs belonging to deleted components are rejected.
  • Quantity replaces the current stock balance. Every changed balance is recorded as an adjustment in transaction history.
  • Valid records are imported even when other rows are rejected. Invalid headers, encoding or malformed CSV reject the entire file.
