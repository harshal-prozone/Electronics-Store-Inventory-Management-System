## Changes

Staff and Admin can create and edit components and filter/download availability reports as required by UC-02, UC-03 and UC-08. Deletion, user and catalogue administration, bulk import and audit review remain Admin-only. Staff can update a reorder threshold on the component edit form; the separate threshold shortcut remains Admin-only. Tests cover direct access, duplicate SKU, preserved quantity, attribution in the audit log, anonymous access, and CSRF.

The dashboard retains its availability chart and adds a stock-by-category bar chart (total active units), plus a separate list of up to ten current low-stock components, ordered by last update. The recent transition-alert list remains historical and may include components no longer low-stock. The chart is server-rendered, not Chart.js. Regression tests check active-only aggregation, changes after stock movements, report agreement, empty inventory, large totals and current low-stock filtering.
